# Maison Pétale — цветочный дом

Промо-сайт и витрина цветочного магазина. Vite 8 + React 19 + TypeScript + Tailwind CSS 4 + Motion 13 + Lenis.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Что на странице

Заставка (цветок распускается, пропускается кликом) → герой с парящими вырезанными цветами и
падающими лепестками (курсор работает как ветер) → бегущие строки → манифест, слова которого
«зажигаются» при прокрутке, и счётчики → каталог с фильтрами и 3D-карточками → сцена, где фото
раскрывается из круга → конструктор букета → горизонтальная лента коллекций → поводы с картинкой
за курсором → четыре шага → подписка → отзывы → галерея с параллаксом колонок → вопросы → футер
с формой обратного звонка.

Корзина хранится в localStorage, оформление заказа — демонстрационное: форма пока никуда не
отправляется. Адрес, телефон, отзывы и цифры в тексте — заглушки, их нужно заменить на настоящие.

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/data/catalog.ts` | букеты, цены, цветы и упаковки конструктора |
| `src/data/media.ts` | подключение всех картинок |
| `src/assets/photos/` | фотографии (webp, 960 px по ширине) |
| `src/assets/cut/` | цветы с прозрачным фоном для героя и декора |
| `src/assets/heads/` | головки цветов без стеблей для конструктора букета |
| `src/components/BouquetStage.tsx` | сцена конструктора: купол цветов, эвкалипт, гипсофила, упаковка, бант |
| `src/components/fx.tsx` | общие эффекты: появление, магнитные кнопки, курсор, счётчики |

## Фотографии

Все снимки взяты со StockSnap.io (лицензия CC0 — можно использовать коммерчески без указания
авторства). Цветы в `src/assets/cut/` вырезаны из этих же снимков нейросетью rembg (isnet).

Pinterest не использовался: там в основном чужие фото без понятных прав. Если нужна конкретная
картинка оттуда — положите файл в `src/assets/photos/` и пропишите его в `media.ts`.

Фото с StockSnap доступны максимум в 960 px по ширине, поэтому на очень больших экранах
полноэкранная сцена «живые цветы» может выглядеть чуть мягче. Для продакшна стоит заменить
её на собственную съёмку.
